# Milcah Chacha Portfolio

A responsive personal portfolio website developed to showcase academic background, professional skills, interests, and personal information. The project demonstrates practical application of web development, backend development, and database management.

## 1. Live Portfolio Website

**Visit the deployed website:**

[Milcah Chacha – Personal Portfolio](https://milcah-chacha-portfolio.netlify.app/)

## 2. GitHub Repository

[View GitHub Repository](https://github.com/Milcah2513/milcah-chacha-portfolio)

## 3. Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, FastAPI
- **Database:** Supabase PostgreSQL
- **Frontend Hosting:** Netlify
- **Backend Hosting:** Render

## 4. Project Structure

- `frontend/` – Contains the website interface and frontend resources.
- `backend/` – Contains the API and database integration.

## 5. Development

The project uses Python and FastAPI for backend development, with Supabase PostgreSQL providing database services.

Backend setup instructions will be added as development progresses.
